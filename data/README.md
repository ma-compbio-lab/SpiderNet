# Data catalog

See [the data guide](../docs/DATA.md). `manifest.json` is the authoritative archive inventory. The archives are uploaded to a restricted Zenodo draft and shared privately with editors and reviewers through the submission materials. Public URLs and DOI fields remain null until public release; private access links are not stored in this repository. Downloaded reviewer ZIPs can already be restored using `scripts/data.py restore --archive-dir`. Installing the Python package does not download research data.
