# SpiderNet

**SpiderNet** is an interpretable deep learning framework for learning cell-cell meta-interactions (MIs) from spatial omics data.  
It enables discovery of directional, biologically meaningful communication modules between cells, and supports a wide range of downstream analyses such as pathway prioritization, subtype discovery, and in-silico perturbation.

## Features

- Learns meta-interactions (sender regulators to ligand-receptor bridges to receiver targets)
- Supports large-scale spatial transcriptomics datasets
- Provides in-silico perturbation and pathway-level inference
